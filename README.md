# Ultimate Tic-Tac-Toe

Ultimate Tic-Tac-Toe is an advanced version of the classic Tic-Tac-Toe game. This project is built using HTML, CSS, and JavaScript. It features a 3x3 grid of Tic-Tac-Toe boards, adding a layer of strategy and complexity to the traditional game.

## Features

- **Interactive Super Board**: Play on a grid of 9 mini Tic-Tac-Toe boards.
- **Dynamic Gameplay**: Each move determines the active mini board for the next player.
- **Winning Detection**: Automatically checks for wins and draws in both mini and super boards.
- **Responsive Design**: Adapts to various screen sizes, including mobile devices.
- **Stylish UI**: Modern and visually appealing interface.

## How to Play?

1. **Objective**: Win three mini boards in a row to win the game.
2. **Moves**: Players take turns placing their marks (X or O) on the active mini board.
3. **Active Mini Board**: The position of the last move dictates the active mini board for the next player.
4. **Winning a Mini Board**: A mini board is won by getting three in a row, column, or diagonal.
5. **Winning the Game**: The game is won by winning three mini boards in a row, column, or diagonal on the super board.

## Installation

To run this game locally:

1. Clone this repository:
    ```bash
    git clone https://github.com/amaanp314/ultimate-tic-tac-toe.git
    ```

2. Navigate to the project directory:
    ```bash
    cd ultimate-tic-tac-toe
    ```

3. Open `index.html` in your preferred web browser.

## File Structure

- **index.html**: The main HTML file.
- **styles.css**: The CSS file for styling the game.
- **script.js**: The JavaScript file containing the game logic.
